# Code of conduct

This project follows the
[Ansible Community Code of Conduct](https://docs.ansible.com/ansible/latest/community/code_of_conduct.html).

It applies to all project spaces: issues, pull requests, and discussions.

Please report unacceptable behaviour to the maintainer listed in
[`.github/CODEOWNERS`](.github/CODEOWNERS), via GitHub. Reports involving a
maintainer may be escalated to the Ansible community team using the contacts in
the policy linked above.
